01

PYTHON · API INTEGRATION

Weather Lookup

Weather conditions, temperature, and humidity for a location using its latitude and longitude, retrieved through an existing API.

How it works

Users enter a latitude and longitude in the terminal. The Python application uses an OpenWeatherMap API to retrieve weather conditions, temperature, and humidity for that location.

Tools and focus

Written entirely in Python, this was my first experience using an API. Learning how to use the API was the biggest challenge; working through examples helped me understand how to retrieve weather data.

02

PYTHON · API INTEGRATION

News Headline Finder

The top two news headlines for a user-selected topic, gathered with Python and NewsAPI.

How it works

Users enter a news topic in the terminal. The Python application uses NewsAPI to retrieve the top two headlines for that topic, displaying each title, description, and publication date.

Tools and focus

The biggest challenges were working with cursor.execute and selecting the information to display. This project gave me practice retrieving API data and presenting relevant details in the terminal.

03

PYTHON · TURTLE

The Shape Series

A visual novel project exploring storytelling through Python’s Turtle graphics module.

In progress

The story

The plan is for players to choose Triangle, Circle, or Square and follow their day through click-through dialogue. They meet at ShapeCo: Triangle is buying groceries, Square works as a cashier, and Circle is buying the latest edition of The Number Series. A shared love of the books sparks a friendship, ending with the three chatting happily in a café.

Planned choices

Multiple endings are planned, with some choices leading to an adventure inside The Number Series. Alternate paths are not implemented yet.

Progress and next steps

The start screen and part of Triangle's storyline are complete. Drawing every scene with Python Turtle has been the biggest challenge. I want to apply what I have learned since starting the project to rework the artwork and improve how players interact with the game.
